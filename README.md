# TFM — Visor GIS Municipal

App web GIS genérica y reutilizable para municipios españoles.
Construida con ArcGIS Maps SDK for JavaScript.

## Estructura
- `app/` — código fuente
- `docs/` — memoria del TFM
- `data/` — configuraciones por municipio

## Cómo ejecutar
Abrir `app/index.html` en un servidor local.
