# geo-modular-app

Visor GIS configurable para administraciones públicas españolas (municipio, provincia, comunidad autónoma), construido con **ArcGIS Maps SDK for JavaScript 5.1**, Calcite 5.1, Web Components y ES Modules nativos. Un único código base: el territorio y el contenido se definen por configuración (`config/deployment.js`), sin reprogramar.

Documentación técnica: `2ARCHITECTURE.md` (arquitectura), `3DECISIONS.md` (decisiones), `BACKLOG.md` (pendiente).
